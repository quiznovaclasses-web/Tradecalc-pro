2) ZIP extract karein aur saari project files apne existing GitHub repository mein replace/upload karein.
3) supabase-config.js ko bilkul same rehne dein.
4) Deploy hone ke baad Admin Dashboard > Articles kholein.
5) Create new article par click karein. Title, slug, 50–320 character intro, article body, cover image URL, SEO title/description fill karein.
6) Monetag placement 1–4 select karein (pehle Monetag ads tab mein placement globally enabled aur saved honi chahiye).
7) Article ke andar dikhane ke liye active affiliate offers select karein.
8) Save as draft ya Publish now choose karein. Published article Trading Platform Offers ke neeche article box mein show hoga.
9) Article ka shareable link: https://YOUR-DOMAIN/?article=your-slug

Latest 10 articles ticker mein continuously neeche se upar scroll honge; pointer/touch hover par animation pause hoti hai. Neeche archive mein Load more articles se purane articles milenge.
